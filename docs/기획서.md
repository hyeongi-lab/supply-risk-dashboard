## 2. 추진 배경

### 2-1. 텅스텐 수급 이슈 사례

- 중국이 텅스텐 등 전략 광물에 대한 수출통제를 시행하면서 국내 조달에 차질이 발생함
- 당사도 원자재 확보 지연으로 공장 가동이 중단되는 피해를 입음
- 수출통제 시행일: ✏️ (예: 2025년 2월, 정확한 날짜 확인)
- 당사 영향: ✏️ 생산 중단 기간, 영향받은 제품·라인, 추정 손실액, 긴급 조달 비용 등

### 2-2. 문제점: 전조 증상이 있었지만 놓쳤다

- 미·중·일 간 수출통제와 보복 조치가 연쇄적으로 이어지는 흐름이 사전에 뉴스와 공식 발표로 드러나 있었음
- 하지만 구매팀이 이를 매일 체계적으로 모니터링하는 수단이 없었음
- 정보가 개인의 관심과 경험에 의존했고, 위험도를 판단하는 기준도 없었음
- ✏️ (추가할 내용이 있으면 작성: 예) 당시 공급사로부터 늦게 통보받음 등)

### 2-3. 해결 방향

글로벌 뉴스, 각국 정부 공고, 원자재 가격을 매일 자동으로 수집하고 AI가 위험도를 판단해, 구매팀이 **사전에** 대응(선확보, 대체 공급선 확보)할 수 있는 조기경보 체계를 만든다.

## 3. 목표 및 기대효과

### 목표

- 핵심 원자재·장납기 소재의 수급 위험을 **매일** 한 화면에서 확인
- 수출통제 등 위험 신호를 **실제 공급 차질 전에** 감지하고 알림
- 정보 수집에 드는 반복 업무를 AI로 자동화

### 기대효과

| 구분 | 현재 (As-Is) | 개선 후 (To-Be) |
| --- | --- | --- |
| 정보 수집 | 담당자가 수동 검색, 비정기 | 매일 자동 수집 |
| 위험 판단 | 개인 경험에 의존 | AI가 기준에 따라 4단계로 판단 |
| 공유 | 메일·구두로 산발 공유 | 대시보드 하나로 팀 전체 공유 |
| 대응 시점 | 공급 차질 발생 후 | 위험 신호 감지 시점 (✏️ 목표: 예) 최소 2주 전) |
| 업무 시간 | ✏️ 현재 정보 수집에 쓰는 시간 (예: 주 3시간) | 하루 5분 확인 |

## 4. 주요 기능

1. **자동 수집 (매일)**: 글로벌 뉴스, 각국 정부 수출통제 공고(중국 상무부, 미국 BIS, 일본 METI 등), 원자재 가격
2. **AI 위험 판단**: 기사별로 관련 소재·국가·이슈 유형을 분류하고 심각도를 매긴 뒤, 당사 감시 품목과 매칭해 위험 단계를 판단
3. **대시보드 (웹)**: 오늘의 위험 신호 TOP 5, 품목별 신호등, 가격 추이 차트, 국가별 이슈 타임라인, AI 일일 브리핑
4. **알림**: '경계' 이상이면 ✏️ (메일 )으로 즉시 알림 하고 웹사이트에 빨강으로 경고등
5. **접속**: 로그인 없이 웹 주소로 접속 (회사 PC 크롬에서 확인)

| 🟢 관심 | 관련 뉴스가 평소 수준 | 대시보드에 표시만 함 |
| 🟡 주의 | 관련 기사가 평소보다 크게 늘어남, 또는 가격이 1주에 10% 이상 오름 | 대시보드 강조, 일일 브리핑에 포함 |

| 🔴 심각 | 당사 품목에 대한 수출통제가 확정·시행됨 | 팀 전체 알림, 긴급 확보·대체선 검토 |

## 7. 시스템 구성

| 구성 | 사용 도구 | 역할 | 비용 |
| --- | --- | --- | --- |
| 개발 언어 | Python | 수집, AI 분석, 화면 전부 | 무료 |
| 웹 화면 | Streamlit (Streamlit Community Cloud) | 대시보드를 24시간 띄움 | 무료 |
| 매일 자동 실행 | GitHub Actions | 매일 아침 수집과 분석 실행 | 무료 |
| 코드·데이터 보관 | GitHub | 코드와 수집 데이터 저장 | 무료 |
| AI 판단 | Claude API | 기사 분류, 위험 판단, 브리핑 작성 | 사용량 과금 |
| 데이터 소스 | GDELT, Google News RSS, 각국 정부 공고, 한국광해광업공단 KOMIS 등 | 뉴스·공고·가격 | 무료 위주 |
| 감시 품목 관리 | Google Sheets (비공개) | 품목·검색 키워드 목록, 매일 자동 반영 | 무료 |

**처리 흐름**: 매일 아침 GitHub Actions 실행 → 뉴스·공고·가격 수집 → Claude API로 위험 판단 → 결과 저장 → 위험하면 알림 → 구매팀이 웹에서 확인

회사 PC에는 설치할 것이 없고, 크롬으로 웹 주소에 접속만 하면 됩니다.

## 8. 보안 및 정보 관리

- 시스템에는 **공개 정보만** 사용 (뉴스, 정부 공고, 시장 가격)
- 재고, 단가, 공급사명, 계약 조건 등 내부 정보는 시스템에 넣지 않음
